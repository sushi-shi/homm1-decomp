# homm1-decomp

C++ reconstruction of **Heroes of Might and Magic** for Windows 95, release 1.0
(`HEROES.EXE`, New World Computing, February 1996), built with the pinned
Visual C++ 4.0 toolchain under Wine. Retail bytes are authoritative; their
hashes live in [config/retail/targets.json](config/retail/targets.json). Supply
your own executable and game assets.

## Quickstart

With Nix flakes enabled, run from the repository root:

```sh
nix develop .#build
homm1 init --exe /path/to/HEROES.EXE
homm1 toolchain install
homm1 tool wine --init
homm1 build
homm1 match BASE/MOUSEMGR
homm1 verify status
homm1 play --data /path/to/HEROES   # optional: run the rebuilt game
```

The editor is supplied with `init --editor-exe /path/to/EDITOR.EXE`. Retail
inputs, the toolchain, Wine state and generated reports stay in ignored
`build/`.

## Versions

Win95 1.0 is the first retail build. Its successors are reconstructed on
[`decomp-win95-1.1`](https://github.com/sushi-shi/homm1-decomp/tree/decomp-win95-1.1) and
[`decomp-win95-1.2`](https://github.com/sushi-shi/homm1-decomp/tree/decomp-win95-1.2), and the Buka 2003 edition on
[`decomp-buka-2003`](https://github.com/sushi-shi/homm1-decomp/tree/decomp-buka-2003), whose
[version lineage](https://github.com/sushi-shi/homm1-decomp/blob/decomp-buka-2003/docs/versions/README.md) records
each step.
