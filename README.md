# homm1-decomp

C++ reconstruction of **Heroes of Might and Magic** for Windows 95, release 1.2
(`HEROESW.EXE`, New World Computing, August 1997), built with the pinned Visual
C++ 4.1 toolchain under Wine. Retail bytes are authoritative; their hashes live
in [config/retail/targets.json](config/retail/targets.json). Supply your own
executable and game assets.

## Quickstart

With Nix flakes enabled, run from the repository root:

```sh
nix develop .#build
homm1 init --exe /path/to/HEROESW.EXE
homm1 toolchain install
homm1 tool wine --init
homm1 build
homm1 match BASE/MOUSEMGR
homm1 verify status
homm1 play --data /path/to/HEROES   # optional: run the rebuilt game
```

The editor is supplied with `init --editor-exe /path/to/EDITORW.EXE`. Retail
inputs, the toolchain, Wine state and generated reports stay in ignored
`build/`.
