# August 1997 compiler and runtime controls

The 1.2 port uses Visual C++ 4.1 (CL 10.10.6038, LINK 3.10.6038),
with the existing per-unit `/Gi` profiles and multithreaded `LIBCMT.LIB`.
This is supported by original-media controls, not just the PE linker stamp.

The preserved Microsoft MSDN July 1996 Disc 2 image is pinned in
`config/toolchains.json`, SHA-256
`babbcd7dcefec092c6168330a9b7b7157b05baea20fe5c593992d0e50ddc1e72`.
The media SHA-1 also agrees with its preservation catalog:
`9f8cbc890e53c0cc22402bb5e69dedc71f83d4a4`.
The [Microsoft utility-version table](https://ftp.zx.net.nz/pub/archive/ftp.microsoft.com/MISC/KB/en-us/93/400.HTM)
identifies these compiler/linker versions as VC4.1.

Real translation units were compiled under both VC4.0 and VC4.1, using the
retail flags and the recovered `F:\H1w95src\Base` /
`F:\h1w95src\source` source roots. Whole-body discovery comparisons mask
COFF relocation operands only. They are compiler controls, not strict scores:
referent identity is validated separately by the normal matching pipeline.

| VC4.1 body matching 1.2 but neither VC4.0/1.2 nor VC4.1/1.1 | 1.2 RVA | Bytes |
|---|---:|---:|
| `hero::AddSpell` | `0x47877` | 483 |
| `hero::HeroScreenUpdate` | `0x481eb` | 171 |
| `hero::UpdateArmies` | `0x48296` | 442 |
| `CanBuy` | `0x22e94` | 206 |
| `QuickViewWait` | `0x24f04` | 149 |
| `townManager::SetArmyCommand` | `0x40bcc` | 950 |
| `townManager::DrawTown` | `0x4340d` | 248 |

The unoptimized `/GX` HISCORE constructor/Open controls and the optimized
INPUTMGR controls also compile and match bodies, but do not distinguish the
compiler versions. Several unchanged bodies retain the VC4.0 shape; this does
not justify a compiler-state search or a claim that every object was rebuilt.

For COFF library functions of at least 24 bytes, relocation-masked body
searches find 242 VC4.1 LIBCMT entries in 1.2 (228 unique locations), versus
181 VC4.0 LIBCMT entries (166 unique). In 1.1 the corresponding counts are
162 and 224. VC4.1-specific matches include the EH handler family,
`_read_lk`, `_write_lk`, `_setenvp`, `_ioinit`, and allocation helpers.
These counts describe library candidate entries, not the game-function census.

## Reproducing the release

`nix-shell scripts/toolchain/create-toolchain-release.nix` extracts hash-pinned
VC4.1, WinG 1.0 and DirectX 1 media and expands the preserved MASM 6.11 disk.
Alternatively, after verified media installation:

```sh
nix develop .#build --command python3 scripts/toolchain/create-toolchain-release.py \
  --from-installed build/toolchains
```

Only the 363 pinned files are packaged, including RC/RCDLL/CVTRES. Archive
order, timestamps, ownership and modes are fixed. Existing VC4.0 releases
remain immutable. Retail MSS32/SMACKW32 DLLs are user runtime inputs and are
not part of the compiler release.
