# Clangd and source extraction

Root `.clangd` points at `build/clangd/compile_commands.json`, generated by
`python3 -m homm1.graph.compdb` as a build edge. It models i386 VC6
(`_MSC_VER=1200`) with era header mirrors and per-unit ABI flags.

Consumers are the source-label extractor, source fingerprints, `homm1 lsp` and
editors. `-ferror-limit=0` prevents a header diagnostic cascade from truncating
navigation below the parser's default error cutoff. `.clangd` adds its flags
after the database's, so its `-fms-compatibility-version` must agree with it. Clang is a reader;
VC6 objects and retail comparison remain the build verdict.

```sh
nix develop .#build
python3 -m homm1.graph.compdb --check
homm1 lsp hover include/BASE/mouseManager.h:10
```

Keep types and owner headers canonical so references and rename operate on a
single symbol identity. Review a bulk rename's diff and rebuild affected TUs.
