# Windows 95 1.2 → Buka 2003

Implementation is in progress on `decomp-buka-2003`, branched from
`decomp-win95-1.2` at `43cf275fee2f181375d208f58b101536bc34fc7c`.
The active target is Buka `HEROES.EXE`, the compiler is VC6 SP5, and the
matching locale is Russian. The NWC score ledger and reports were retired;
there is no strict Buka score yet. Inherited address tables and source claims
still need migration. The reviewed absolute-reference manifest is installed.

The device, Ogg music and sample implementations are enrolled in `units.toml`:
[`Audio.cpp`](../src/BASE/Audio.cpp),
[`AudiereMusic.cpp`](../src/BASE/AudiereMusic.cpp) and
[`AudiereEffects.cpp`](../src/BASE/AudiereEffects.cpp). Callers use the new
free functions; the old sound manager is removed. The video loop is rebuilt in
[`SMACKMGR.cpp`](../src/SOURCE/SMACKMGR.cpp). All translation units compile.
Buka-specific source identities remain documented comments and retail facts
until the census/reference review admits them to strict comparison.

Reconstruction uses retail instructions and generated CFGs. Decompiler output
is prohibited. The existing HoMM2 `analysis/disasm.py` CFG and skeleton-diff
helpers support the temporary instruction-correspondence reviews alongside
HoMM1's `sema disasm --blocks`. Full matching reports remain unavailable until
strict delinking succeeds. No separate adapter was installed.

## Confirmed differences

These observations come from the pinned local executable, not from a translated
source donor. Full input hashes and PE inventories are in
[`config/retail/buka-2003.json`](../config/retail/buka-2003.json).

| Area | NWC 1.2 | Buka 2003 |
| --- | --- | --- |
| Compiler | VC4.1, incremental `/Gi` | VC6, mostly `/Od`; FINDPATH/SEARCH use `/O2 /Ob2 /G5`; immediate assertion lines |
| Link | Base relocation directory present | `/FIXED`; absolute sites must be recovered and reviewed |
| Imports | Separate `.idata` | Import directory in `.rdata` |
| Text | Original English | Russian executable text, Windows-1251 bytes |
| Audio | CD MCI and Miles digital music | New Audiere playback routines; Ogg music paths |
| Smacker | Named imports | Nine ordinal imports from the shipped Watcom-built DLL |
| Registry | NWC installation key | `SOFTWARE\Buka\3DO\Heroes of Might and Magic Platinum\1.000` |

The adventure screen also changes audio handling. `Open` restores both volume
channels, and `Close` stops samples before music through `StopAllAudio`:

```diff
- SetEffectsVolume(gConfig.soundVolume);
+ SetVolumes(gConfig.soundVolume, gConfig.musicVolume);

- StopMusic();
- StopAllSamples();
+ StopAllAudio();
```

Movement samples use full volume (127), up from 64. Closing the adventure
screen now skips null cursor samples before disposing them:

```diff
- CURSOR_SAMPLE_VOLUME = 0x40,
+ CURSOR_SAMPLE_VOLUME = 127,

- gpResourceManager->Dispose(m_cursorSamples[index]);
+ if (m_cursorSamples[index])
+     gpResourceManager->Dispose(m_cursorSamples[index]);
```

The restart, load and quit confirmation prompts in `Main` use catalog IDs.
Their original English is preserved in `messages.def`; the Russian strings
come from the corresponding retail instruction operands and live in `ru.po`.
The six adventure-button help entries now use the same catalog treatment,
with all original English preserved and every Russian pointer/literal checked.
The map/status help, end-turn confirmation and eight artifact-search messages
also use catalog IDs. Their original English and complete Russian payloads
are preserved and checked against both executables:

```diff
- NormalDialog("Try searching on clear ground.", NORMAL_DIALOG_TYPE_OK);
+ NormalDialog(localization::Tr("adventure.search.clear_ground"), NORMAL_DIALOG_TYPE_OK);
```
The instruction and CFG evidence for these changes is recorded in
[`buka-advmgr.json`](../config/retail/buka-advmgr.json).

Mine quick info uses a new seven-entry table of complete Russian mine names,
rather than appending a separate translated “Mine” suffix to a resource name:

```diff
- sprintf(gText, "\n\n%s %s", gResourceNames[resource], "Mine");
+ sprintf(gText, "\n\n%s", gMineNames[resource]);
```

The English catalog preserves the original composed wording for every entry
(for example, `Gold Mine`). Russian mine names, terrain/object labels and
quick-info labels live only in `ru.po`. The corresponding retail table and
instruction operands are recorded in
[`buka-quick-info.json`](../config/retail/buka-quick-info.json).

The import directory contains two Audiere entry points, `_AdrOpenDevice@8`
and `_AdrOpenSampleSource@4`. Music playback at RVA `0x692fd` selects between
`%sHeroes%02d.ogg` and `%s%s%02d-AudioTrack %02d.ogg`; stop at `0x69742`
retains a seek position for repeatable tracks. The second path uses the CD-track
mapping table. These are replacement routines, not renamed old sound-manager
members. A caller-based correspondence in this region is therefore not proof
of function identity.

Registry values changed as well as the key (`ReadPrefsFromRegistry` at
RVA `0x43f8f`). For example:

```diff
- "Music Volume"
- "Sound Volume"
- "CDDrive"
+ "HMM1 MusicVolume"
+ "HMM1 FXVolume"
+ "HMM1 CDDrive"
```

The CD setup routine at RVA `0x44774` now checks for
`Tracks\02-AudioTrack 02.ogg`. It first validates the local `HEROES.AGG`,
then tries the registered readable drive, then scans CD drives. The existing
NWC launcher’s `_autorun/autorun.exe` stand-in does not satisfy this check.

```diff
- sprintf(path, "%s\\_autorun\\autorun.exe", cdPath);
+ sprintf(path, "%s%s", cdPath, "Tracks\\02-AudioTrack 02.ogg");
```

Audiere initialization at RVA `0x69bd5` first opens `winmm`. A retail quirk
is preserved in `InitAudio`: when that fails but the default
device opens, the routine releases that device again and returns true. Both
the release call and the true return were checked in assembly. A successful
initialization return therefore does not prove an active device.

Changing the music source (`SetMusicSource`, RVA `0x698fb`) stops and releases
the existing stream, clears every saved position, and restarts the previous
track from the beginning. Playing the already selected track resumes a stopped
stream without reopening the Ogg file. A failed source/stream open stops the old
music; a successful open starts the new stream before stopping the old one.

```diff
- gpSoundManager->SwitchAmbientMusic(track);
+ PlayMusic(track);
```

Music suspension is a nesting counter. Play, stop and volume-refresh return
while its value is positive; changing the source still clears and releases the
old state, although its restart calls the guarded play routine. The volume
lookup uses the configuration index directly, without clamping it.

Sample loading also changed (`sample::sample` at RVA `0x75050`): the
constructor now takes only a filename, sets full volume and a false repeat
flag, defaults to 44100 Hz / 16-bit / stereo before decoding the suffix,
allocates through the C++ allocation helper, and adds `0x80` to **every loaded byte**.
The conversion loop is unconditional in retail, including a 16-bit suffix.
The packed sample is now `0x2a` bytes; the active Miles handle and channel
selector are gone, and sample format and stereo are separate fields.

```diff
- sample(name, channelType, volume, loopCount);
- buffer = malloc(size);
+ sample(name);
+ buffer = new char[size];
+ for (unsigned i = 0; i < size; ++i)
+     buffer[i] += 0x80;
```

Audiere interprets the repeat flag as `flag != 0`; retaining the old Miles
one-pass value `1` would instead loop samples. Per-sample volume is scaled by
`127.0f`. Music has 100 saved-position slots and a 100-entry **32-bit** CD-track
map, including track 99 → disc track 50. The disc has the matching local and
CD Ogg files for all 49 mapped tracks. Typed layouts, track mappings and volume
constants are recorded in [`buka-audio.json`](../config/retail/buka-audio.json).

The following text example has a verified pointer-table correspondence:

```diff
- "Wood"
+ localization::Tr("table.gResourceNames.0")
```

`locales/messages.def` retains `Wood`; `locales/ru.po` holds the retail Russian
text. Only generated files under `build/` contain CP1251 escapes. All 565 migrated
table entries have explicit old/new pointer slots, literal RVAs, source
provenance, and byte hashes in
[`buka-localization.tsv`](../config/retail/buka-localization.tsv).
The source uses those catalog IDs. The Buka target selects Russian; the
original English remains in `messages.def` for English exports.

## Validation and remaining work

`e0689d3f71b2942b544fd677cb54085a13503d7b`. It validates contextual IDs,
English `msgid` provenance, duplicate/fuzzy/missing entries, printf signatures,
and strict CP1251 encoding. Clang receives source overlays preserving authored

build dependencies and expanded literals participate in source fingerprints.
Nonmatching locale compilation is restricted to `build/ordinary/<locale>`.
Earlier catalog and relocation checks passed, and the English/Russian clean
exports were validated against the former 1.2 control. Those results are
historical; they do not validate the newly activated Buka candidate.

The reviewed Buka function census replaces the NWC boundaries. The current
`homm1 build` compiles all source units and consumes the reviewed `/FIXED`

(`0x8e968`); most source/data claims still carry inherited NWC addresses.
`homm1 build verify` cannot complete until those identities are reconstructed.

The whole-tree tooling

and verifying both locales, candidate linking, clean exports and runtime.

## Reviewed absolute references

[`absolute_relocations.tsv`](../config/retail/absolute_relocations.tsv) is bound
to the exact Buka executable SHA-256. Its 17,553 fields comprise 14,326
instruction operands, 1,226 in-code dispatch slots and 2,001 data fields
(including 64 unaligned CRT dispatch slots). Per-site instructions and evidence
are in [`absolute_reference_evidence.tsv`](../config/retail/absolute_reference_evidence.tsv);
typed controls, rejected candidates and limitations are in
[`buka-absolute-references.json`](../config/retail/buka-absolute-references.json).

Recursive CFG traversal starts from the reviewed census, direct branches and
calls, dispatch targets and CRT callback pointers. It has no decode errors or
overlapping instructions. Two internal CRT `fld` operands were independently
reviewed outside that entry traversal. The assembly `memcpy`/`memmove` tables
need their actual index bounds: an unused index-zero slot overlaps an
instruction, while valid entries follow it. They cannot be recovered by a
blind run of pointer-shaped words.

Every byte alignment in initialized `.data`/`.rdata` was reviewed. Of 2,276
pointer-shaped candidates, 2,001 are pointer fields and 275 are numeric values,
floating-point bytes, literal contents or PE metadata. Full typed source
initializers and 282 complete VC6 data contributions corroborate that review.
The independent CRT control covers 1,776 admitted absolute fields; 51 other
COFF DIR32 fixups resolve the absolute-zero `__except_list` symbol in `fs:[0]`
and are not image-relative references. Three further sweep candidates are
UTF-16 resource-name windows. Relative to the initial sweep, the reviewed map
adds 321 fields and removes 98. No admitted four-byte fields overlap.

The pinned delinker now accepts the manifest and uses the PE IAT directory
even when imports live in `.rdata`. The synthetic PDB uses the actual PE
section and offset for each import. Retained PE relocation directories take
precedence. A control using the existing NWC 1.2 PDB and manifests produces
identical hashes for all 72 objects with the old and updated delinkers.

The 45 inherited NWC relocation-alias rows are archived in
[`nwc-1.2-reloc-referents.tsv`](../config/retail/nwc-1.2-reloc-referents.tsv).
None is applied to Buka without a new operand/owner proof. Unknown code bands
also retain the game-data identity requirement; only reviewed library evidence
can grant the library exemption. Thus this reference map makes the strict
migration work visible; it does not establish source ownership or matching
completion.

```diff
- destinationX += normalDirTable[static_cast<i16>(direction + 4) & 7].x;
- destinationY += normalDirTable[static_cast<i16>(direction + 4) & 7].y;
+ i16 backDirection = (direction + 4) & 7;
```

also use `> 0`, corroborated by the donor. These changes recover emitted

FindCombatPath retains one instruction-order difference. These are not strict

## Sample and video control-flow review

`WaitSample` waits while the Audiere stream plays and calls `DelayMilli(10)`
between polls. It then cleans up the stream node; it does not dispose the sample
resource. Combat and AI callers use separate nested sample/music suspension
counters. Combat temporarily resumes suspended channels and restores the saved
music track and suspension state when closing.

```diff
- WaitEndSample(handle, timeout);
+ WaitSample(resource);
```

Smacker now has a direct playback loop, six 27-byte movie-option rows, and a
natural-completion return value. The introduction sequence is:

```diff
- PlaySmacker(slowVideo ? SMACK_NWCLOGO1 : SMACK_NWCLOGO);
- PlaySmacker(slowVideo ? SMACK_INTRO02C : SMACK_INTRO02U);
+ if (!gSkipIntro && PlaySmacker(SMACK_BUKA) && PlaySmacker(SMACK_NWCLOGO))
+     PlaySmacker(SMACK_INTRO);
```

Before playback, Buka stops music, closes Audiere, selects the first supported
format from twelve WinMM choices and opens a temporary Miles driver. After
closing the movies and driver it reinitializes Audiere, restores both palette
states and the cursor, and releases movie resources. Movie volume uses the
effects volume setting. The winning-movie caption begins at frame 22, at
(32, 342) in a 320 by 106 rectangle, using color 4. The original English winning
text remains authored in KB; its remaining Buka localization is still pending.
The six retail option rows currently leave companion filenames empty, but the
surviving companion playback path is retained.

Retail facts and source identities are in
[`buka-video.json`](../config/retail/buka-video.json). The movie loop's 72-block
CFG agrees with the generated source CFG, as do its instruction lengths and
branch targets. Remaining body differences are local stack slots and frame
size. No padding locals or permutations were used to conceal them.

The sample constructor and destructor agree with retail under `/G5`, including
the constructor's embedded switch tables. `/G6` adds register clears before two
short file-ID arguments, so SAMPLE uses a measured separate profile. This is
instruction-body evidence, not a strict score: ordered references, EH/helpers,

## Disc discovery

Buka replaces the old MCI/autorun probe with an Ogg-file check:

```diff
- sprintf(gText, "%s\\_autorun\\autorun.exe", gcRegCDRomPath);
+ sprintf(gText, "%s%s", gcRegCDRomPath, gcCDTrackName);
```

The track path is `Tracks\02-AudioTrack 02.ogg` without a leading backslash.
Buka first checks local `DATA/HEROES.AGG`, changing to the registered install
directory if needed. It accepts a registered drive only when its uppercase
letter is valid, `GetDiskFreeSpaceExA` succeeds with critical-error dialogs
suppressed, and the track opens. Otherwise it tries each CD-ROM drive twice,
checks the track's final 100 bytes, and records `HMM1 CDDrive` under the Buka
Platinum `1.000` registry key. Each unsuccessful pass sleeps three seconds.
The old MCI commands and sound/animation path rewriting are gone.

Retail quirks are retained: only 26 bytes of the 26 integer drive slots are
cleared; the probe path is drive-relative; a short read is accepted unless it
returns -1; registry-open failure does not invalidate a successful disc probe.
The generated CFG has 40 blocks. All branch edges and block instruction counts
agree under `/G5`; stack layout remains open. A separate complete-TU control
shows `IsCDDrive`'s boolean return body agrees under `/G5`, whereas `/G6` emits
a different arithmetic sequence. `SOURCE/KB` and `SOURCE/kbwin` therefore use
the measured `/G5` profile. This is diagnostic body evidence, not an enrolled
strict score. See `config/retail/buka-cd-setup.json`.
