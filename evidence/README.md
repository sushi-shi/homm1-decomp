# Evidence

`homm1 init` regenerates binary-derived reports in ignored `build/analysis/`.
Each report includes the input SHA-256, image layout, imports, exports, base
relocations, and embedded source paths with their RVAs. These are observations,
not function boundaries or reconstruction claims.

Commit reviewed analysis here with the target hash, addresses, reproduction
command, and a distinction between observations and hypotheses. The existing
target survey is preserved in the root README.
